# EmailService - Сервис управления рассылками
Веб-приложение для создания и управления email-рассылками.

## Функционал

1. Управление сообщениями
- Создание шаблонов сообщений;
- Редактирование сообщений;
- Просмотр списка сообщений;
- Удаление сообщений.

2. Управление клиентами
- Добавление клиентов(email, ФИО, комментарии);
- Просмотр списка клиентов;
- Редактирование данных;
- Удаление.

3. Управление рассылками
- Создание рассылки с выбором сообщения и получателей;
- Настройка времени начала и окончания рассылки;
- Автоматическое обновление статуса;
- Просмотр детальной информации рассылок;
- Редактирование.

4. Кеширование
- Кеширование главной страницы (15 минут);
- Кеширование списка рассылок (5 минут);
- Использование Redis для хранения кеша.

## Установка
1. Клонирование репозитория
```
git clone https://github.com/Sofya-Ageeva/EmailService.git
cd EmailService
```

2. Создание и активация виртуального окружения
 2.1. Для macOS/Linux
```
python -m venv venv
source venv/bin/activate
```
 2.2. Для Windows
```
python -m venv venv
venv/Scripts/activate
```
3. Установка зависимостей
```
pip install -r requirements.txt
```

4. Настройка уязвимых данных
```
cp .env.template .env
```
Отредактируйте файл .env

5. Запуск Redis (для кэширования)
```
brew install redis
brew services start redis
```
6. Миграция и запуск

```
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```
